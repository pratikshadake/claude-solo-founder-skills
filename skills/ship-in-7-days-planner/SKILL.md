# Skill: Ship in 7 Days

## Purpose
Create an aggressive execution plan to launch within one week.

## Steps
1. Freeze scope.
2. Remove polish.
3. Prefer templates and existing tools.
4. Break work into daily milestones.

## Output
Day-by-day launch plan.
