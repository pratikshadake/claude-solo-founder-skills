# Skill: MVP Scoper

## Purpose
Define the smallest possible product that delivers real user value
and can be built quickly.

## When to Use
- New startup idea
- Large feature request
- Pre-build planning

## Steps
1. Identify the core user problem.
2. Define the single success outcome.
3. List all possible features.
4. Cut scope to the minimum testable set.
5. Ensure buildable in ≤ 14 days.

## Output

### Problem
### Target User
### Core Outcome
### MVP Features
### Explicit Non-Goals
### Build Time Estimate
