# Example: MVP Scope for AI Travel Planner

## Problem
Travel planning is fragmented across many sites.

## Target User
Busy professionals planning international trips.

## Core Outcome
Generate a complete 5-day itinerary in 60 seconds.

## MVP Features
- Destination input
- AI itinerary generation
- Downloadable PDF

## Non-Goals
- Bookings
- Payments
- Collaboration

## Build Time
10–12 days
