# Claude Solo Founder Skills

Production-grade **Claude Code skills** designed for:

- Solo founders shipping fast  
- Startup engineers making real decisions  
- Builders who want execution speed **without losing rigor**

This repository focuses on what most AI prompt libraries miss:

> **Decision quality, production thinking, and real-world startup execution.**

---

# What are Claude Skills?

Claude Code skills are **Markdown playbooks** that Claude automatically loads to guide:

- reasoning  
- workflows  
- safety checks  
- output structure  

Think of them as:

> **Reusable decision engines for software builders.**

Drop them into: claude/skills/ 
…and Claude will start using them.

---

# Included Skill

## Build vs Buy Decision Engine

A rigorous framework to decide whether to:

- build internally  
- purchase a SaaS/tool  
- or take a hybrid approach  

Designed to reflect **CTO-level reasoning**, not generic AI summaries.

**Covers:**

- Time to value  
- Total cost of ownership (24-month view)  
- Strategic differentiation  
- Control, risk, and lock-in  
- Opportunity cost of engineering time  

See:

- `.claude/skills/build-vs-buy.md`
- `examples/build-vs-buy-example.md`
